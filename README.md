# North High

**North High** is a game project by **PrimeGravity**.

## Download

The repository currently contains the Windows 64-bit game build at [`release/NorthHighGame.exe`](release/NorthHighGame.exe). Download the executable from that file's GitHub page using **Download raw file**.

The uploaded build is a 64-bit Windows GUI executable. The game version, system requirements, controls, and gameplay description have not been provided, so they are not specified here. This repository currently contains the game executable only; it does not include the Godot project files or source code.
